# Window Buddy

Window Buddy is a simple desktop pet that lives on your screen and reacts to your interactions.

<img width="1338" height="1175" alt="image" src="https://github.com/user-attachments/assets/54d124d6-0a42-4568-b350-bde16bb8d0d6" />


## Available Controls

- **Double Click** — Makes the pet happy.
- **More than 2 continuous clicks** — Makes the pet angry.
- **Left Arrow** — Moves the pet to the left.
- **Right Arrow** — Moves the pet to the right.
- **Drag** — Drag the pet anywhere on your screen.

## Features
- 2D pet
- Pet that shows emotions based on how we interact with it
- Always available
